The worst-case complexity of Quicksort using the Median-of-three pivot technique is still O(n^2) because it only randomly samples three elements. In theory, it is entirely possible to create a special input array such that the median of the first, middle, and last three elements at each recursive step always falls on the second-smallest or second-largest element in the array. When that happens, the array will be continuously split in an extremely unbalanced way, causing the depth of the recursive tree to be maximally skewed and pushing the total execution time of the algorithm back to the worst-case scenario of O(n^2).
